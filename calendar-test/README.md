# 달력(.ics) 알림 격리 시험판

〈한약 드실게요〉 공개 앱과 **분리된 시험 페이지**예요. 공개 앱 파일(`index.html`, `app.js`, `app.css`, `sw.js`, `manifest.webmanifest`)은 바꾸지 않았어요.
근거: [Tess] 달력 알림 격리 시험판 개발 지시서 (2026-10-28), Socra 승인 (2026-11-03).

- 주소(병합 후): `https://socraxtess.github.io/hanyak-drink-pwa/calendar-test/`. 공개 앱에서는 링크하지 않았고, 검색 노출은 막아 두었어요(`noindex`).
- 하는 일: 복용 시작일·기간·하루 횟수·시각을 받아 **휴대폰 브라우저 안에서** `.ics` 파일을 만들어요. 서버로 보내는 것은 없어요.
- 일정 구성: 복용 시각마다 일정 1개씩 만들어요. 각 일정은 "매일 반복, 복용 기간(일)만큼"이고, **정각 알림 1개**가 붙어요(사전 알림 없음). 제목은 `🍵 복약 알림`이고, 설명에는 복용 안내와 앱 주소만 넣어요.
- 공개 앱 데이터(`hanyak.v1`)는 '불러오기' 버튼을 눌렀을 때 **읽기만** 해요. 쓰거나 지우지 않아요.

## ⚠️ 시험할 때 꼭 지켜 주세요: 공개 앱을 쓰는 브라우저에서는 열리지 않아요

공개 앱의 서비스 워커는 같은 사이트의 모든 화면 요청에 **공개 앱 첫 화면**을 돌려줘요. 그래서 〈한약 드실게요〉를 이미 쓰고 있는 브라우저에서 시험 주소를 열면 공개 앱이 떠요(자동 시험으로 확인함).

**시험할 때는 아래 중 하나로 열어 주세요.**
- **Chrome 시크릿 탭**: 공개 앱 데이터가 없는 상태라 '불러오기'는 보이지 않아요. 직접 입력해 주세요.
- 공개 앱을 설치하지 않은 **다른 브라우저**: 예를 들어 앱을 Chrome에 설치했다면 삼성 인터넷으로 열기.
- 공개 앱을 쓰지 않는 휴대폰

이 제약을 없애려면 공개 앱 `sw.js`를 한 줄 고쳐야 해요. 공개 앱을 건드리는 일이라 이번 시험판에는 넣지 않았어요. 정식 반영을 결정할 때 함께 다룰 항목이에요.

## 알려진 한계 (환자 안내 전 확인할 것)

- 달력 알림에서는 약사발 영상·음성이 나오지 않아요. 알림 속 주소를 누르면 공개 앱 **첫 화면**이 열려요. 복용 시각이 지났다면 "지금 드실 한약이 있어요 → 마셨어요"가 보여요. 영상은 공개 앱 알림을 눌러 들어왔을 때만 재생되는 기존 원칙을 유지했어요.
- 복용을 바꾸거나 멈춰도 달력 일정은 저절로 바뀌지 않아요. 환자가 직접 지워야 해요.
- 구글 캘린더는 가져온 파일의 알림 대신 사용자 기본 알림 설정을 쓸 수 있다고 알려져 있어요. **확인되지 않은 내용이라 실측으로 판단**해야 해요.
- iPhone은 `data:` 주소로 '캘린더에 추가' 화면을 여는 방식을 넣었지만 **확인되지 않았어요.**
- 실측 전에는 "앱을 닫아도 반드시 울린다"고 안내하지 마세요.
