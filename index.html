시작하기

아래 순서대로 한 번만 해 주세요.

  1. 복용 일정 설정

    하루 복용 횟수, 시간, 기간을 입력합니다. 접수실에서 도와드려요.

  2. 폰 달력에 알림 넣기

    일정을 저장하면 폰 달력에 넣기 화면이 이어집니다. 파일을 눌러 달력 앱에서 저장하면, 앱을 닫아도 달력이 정해진 시간에 알려 줘요.

  3. (선택) 홈 화면에 설치

    설치하지 않아도 달력 알림은 와요. 아이콘으로 열고 싶을 때만 설치하세요.

    설치된 앱으로 실행 중입니다 ✓

    삼성 인터넷 : 아래쪽 ≡ 메뉴 → 현재 페이지 추가 → 홈 화면

    Chrome : 오른쪽 위 ⋮ → 홈 화면에 추가 (또는 앱 설치)

    iPhone : Safari 아래 공유 버튼 → 홈 화면에 추가

폰 달력에 알림 넣기

폰 달력에 넣어 두면 앱을 닫아도 정해진 시간에 달력이 알려 줘요.

넣기 전에 확인해 주세요

  • 알림 제목은 ‘🍵 복약 알림’이에요. 이름·진단·처방·전화번호는 넣지 않아요.
  • 달력 알림은 잠금 화면에 보일 수 있고, 공유 달력에 넣으면 다른 사람도 볼 수 있어요.
  • 일정은 폰 달력(삼성·구글·iCloud 등)에 저장되고, 달력 설정에 따라 클라우드에 동기화될 수 있어요. 저희 서버로 보내는 것은 없어요.
  • 달력 알림에서는 약사발 영상이 나오지 않아요. 알림 속 주소를 누르면 이 앱이 열리고 마셨어요를 누를 수 있어요.
  • 복용 일정이 바뀌거나 중간에 멈춰도 달력 일정은 저절로 지워지지 않아요. 아래 방법으로 지워 주세요.

내려받은 파일 ‘한약복약알림.ics’를 눌러 달력 앱을 고른 뒤 저장을 눌러 주세요. 같은 파일을 두 번 넣으면 일정이 두 번 생길 수 있어요.

달력에서 지우는 방법

  1. 달력 앱에서 ‘🍵 복약 알림’ 일정을 누르기
  2. 삭제 누르기
  3. ‘이 일정 및 이후 일정’ 또는 ‘모든 일정’ 고르기

하루 2~3회라면 시각마다 일정이 따로 있어서, 시각마다 한 번씩 지워 주세요.
