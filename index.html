한약 드실게요

시험용 웹 버전 · 앱을 완전히 닫으면 알림이 오지 않을 수 있어요

시작하기

아래 순서대로 한 번만 해 주세요.

  1. 홈 화면에 설치

    설치된 앱으로 실행 중입니다 ✓

    삼성 인터넷 : 아래쪽 ≡ 메뉴 → 현재 페이지 추가 → 홈 화면

    Chrome : 오른쪽 위 ⋮ → 홈 화면에 추가 (또는 앱 설치)

    iPhone : Safari 아래 공유 버튼 → 홈 화면에 추가

  2. 홈 화면의 ‘한약 드실게요’ 아이콘으로 열기

    설치 후에는 인터넷 창이 아니라 홈 화면 아이콘으로 열어 주세요.

  3. 복용 일정 설정

    하루 복용 횟수, 시간, 기간을 입력합니다. 한의원에서 도와드려요.

  4. 알림 허용

    “알림을 허용할까요?” 창이 뜨면 허용을 눌러 주세요.

  5. 테스트 알림 확인

    설정 화면의 테스트 알림 보내기로 알림이 오는지 확인합니다.
